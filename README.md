# MOGGER — Hard Mode

Одностраничное PWA для iPhone: чёткий план до 31 августа — снять отёк, прокачать челюсть, высушить тело.

## Что внутри

- **Главная** — обратный отсчёт до 31 августа, прогресс цели, дневной чек-лист (10 пунктов с сохранением в `localStorage`).
- **Лицо** — mewing, chin tucks, дренаж, гуаша, mastic gum.
- **Анти-отёк** — приоритеты, утренний шаблон, разбор мифов.
- **Тело** — Push/Pull/Legs/Conditioning со штангой, турником и резинками. Гайд по скакалке для начинающих с видео.
- **Советы** — что реально работает: холод, осанка, сон, скин-минимум, менталка.
- **Заработок** — идеи по возрасту: «до 14 — без ИП», 13–15 / 16–17 / 18–21 / 22+ и отдельная вертикаль AI/нейросети 2025. В каждой карточке раскрывающийся **Мануал** с пошаговой инструкцией и ссылками на бесплатное обучение (YouTube, статьи, инструменты).

## Стек

Один файл `index.html`. Без зависимостей. CSS-анимации, тёмно-синий glassmorphism, SVG-иконки.

## Добавить на iPhone

1. Открой URL в **Safari** (важно — именно Safari, не Chrome).
2. Поделиться → **«На экран Домой»**.
3. Готово — иконка появится как у обычного приложения, запускается на полный экран.

## Локально

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```
